# 🗓️ datenight-js

A JavaScript project that formats dates like a pro! Built as part of the [freeCodeCamp](https://www.freecodecamp.org) curriculum to explore the powerful `Date` object and learn how to present time in human-friendly formats.

## 🚀 Project Goal

Turn a raw `Date` object into a readable string format like:



## 🧠 What I Learned

- Creating and manipulating `Date` objects in JavaScript
- Using `getDate()`, `getMonth()`, and `getFullYear()`
- Zero-based month handling and proper formatting
- Clean string concatenation for dynamic output

## 📦 Built With

- HTML
- JavaScript

## 🛠️ Usage

Open `index.html` in your browser and view the formatted date either in the UI or console.

## 🌱 Why “datenight-js”?

Because turning `2025-04-09T18:30:00.000Z` into **April 9, 2025** is kind of romantic — it’s giving structure to chaos. 🥰
