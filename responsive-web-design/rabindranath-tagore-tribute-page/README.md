# 📜 Rabindranath Tagore Tribute Page

A tribute webpage dedicated to **Rabindranath Tagore**, showcasing his life, achievements, and selected poems.

## 🌟 Features

* Biography of Rabindranath Tagore
* Collection of 10 famous poems
* Clean and simple layout
* Organized content for easy reading

## 🛠️ Built With

* HTML
* CSS

## 🎯 Purpose

This project was created as part of my web development learning journey through freeCodeCamp. It helped me practice structuring webpages and presenting meaningful content.

## 📂 Project Structure

* `tribute-page.html` → Main webpage
* `styles.css` → Styling
* `img/` → Images used in the project
* `font/` → Custom fonts
